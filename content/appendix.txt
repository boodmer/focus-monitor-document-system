CH0_H2|Phụ lục A: Hướng dẫn cài đặt và chạy hệ thống

Hệ thống bao gồm hai thành phần cần khởi chạy độc lập: Backend API (Python/FastAPI) và Frontend Web (React/Vite).

Yêu cầu môi trường:
- Python 3.10 trở lên và Node.js 18 trở lên.
- PostgreSQL đã được cài sẵn phần mở rộng pgvector.
- Trình duyệt Google Chrome hoặc Microsoft Edge (hỗ trợ WebAssembly).
- Webcam có độ phân giải tối thiểu 720p.

Các bước khởi chạy Backend:

1. Sao chép tệp `.env.example` thành `.env` và điền thông tin kết nối database, `SECRET_KEY` và `ALGORITHM` (HS256).
2. Cài đặt các thư viện phụ thuộc bằng lệnh: `pip install -r requirements.txt`
3. Khởi chạy server với lệnh: `python app/main.py`
4. Backend tự động khởi tạo các bảng database và dữ liệu mẫu (seed) qua cơ chế lifespan. API được phục vụ tại `http://localhost:8000`.

Các bước khởi chạy Frontend:

1. Sao chép tệp `.env.example` thành `.env` và cập nhật địa chỉ Backend API.
2. Cài đặt các gói Node.js bằng lệnh: `npm install`
3. Khởi chạy giao diện bằng lệnh: `npm run dev`
4. Truy cập `http://localhost:5173` để sử dụng hệ thống.

CH0_H2|Phụ lục D: Cấu trúc gói tin Heartbeat

Đây là cấu trúc thực tế của một yêu cầu HTTP Heartbeat được trình duyệt gửi lên Backend mỗi 5 giây. Gói tin bao gồm ba HTTP Header phục vụ xác thực HMAC-SHA256 và phần thân JSON chứa dữ liệu giám sát:

```text
POST /api/session/heartbeat HTTP/1.1
Authorization: Bearer <JWT Token>
Content-Type: application/json
X-Signature: a1b2c3d4e5...   (HMAC-SHA256 của chuỗi canonical)
X-Nonce: 550e8400-e29b-...   (UUID ngẫu nhiên chống replay attack)
X-Timestamp: 1714550400       (UNIX epoch giây, cửa sổ ±30s)
```

Phần thân JSON (Request Body):

```json
{
  "session_id": "a3f1c2d4-...",
  "timestamp": 1714550400,
  "focus_score": 78.5,
  "focus_percent": 0.785,
  "state": "FOCUSED",
  "blink_rate": 14,
  "avg_ear": 0.312,
  "head_pose": "CENTER",
  "emotion": "NEUTRAL",
  "identity_status": "VERIFIED",
  "identity_score": 0.91,
  "violations": {
    "multi_face": false,
    "absent": false,
    "identity_mismatch": false
  }
}
```

Quy trình ký HMAC-SHA256 trên trình duyệt sử dụng Web Crypto API theo giao thức: canonical = "{timestamp}.{nonce}.{SHA256(body)}", sau đó signature = HMAC-SHA256(hmac_secret, canonical). Máy chủ tái tạo chữ ký từ cùng các tham số để xác minh tính toàn vẹn gói tin.
